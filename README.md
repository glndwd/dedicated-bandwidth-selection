## 专线网络带宽和普通宽带差在哪？四个具体区别

核心差别只有一个：资源是独享还是共享。往下拆，是四个能直接感受到的差异。

- **独享 vs 共享池**：家庭宽带标称的 200M 是“共享池”概念，运营商按 10:1 的收敛比配置，10 户共享 200M，实际可用带宽随在线人数波动；专线 200M 就是 200M 归一家用，晚高峰也一样。
- **上下行是否对等**：100M 专线意味着双向都能稳定跑 100Mbps；家庭宽带下行标 200M，上行通常压在 30M 以内。视频会议、文件同步、监控回传这类双向流量大的业务，先卡住的就是上行。
- **固定公网 IP**：专线标配固定公网 IP，这是自建服务器、组建 VPN、对接政务监管平台（比如智慧工地对接住建局系统）的前提。共享宽带给的是动态 IP，这些事做不了。
- **保障等级**：专线通过物理隔离建立专属传输通道，配 SLA 服务等级协议，可用性一般承诺 99.99%；共享宽带只是逻辑隔离，碰到市政施工、光缆中断，恢复时间没有硬性承诺。

## 五类专线接入方式，特点和价格差很多

常见的企业专线接入方式有五类，差别主要在传输方式、时延和年费上：

| 接入方式 | 关键特点 | 适合的场景 |
| --- | --- | --- |
| DDN 数字专线 | 点对点透明传输，典型时延 ≤40ms，通信保密性强 | 银行网点、连锁机构的高频数据同步，金融保险客户 |
| SDH 光传输专线 | 独立光通道，2M–10G 带宽，支持 1+1 冗余保护 | 金融交易系统、政务专网等不能中断的关键业务 |
| MSTP 多业务平台 | TDM/IP 双模传输，一条线路同时承载多种业务 | 智慧园区这类要同时跑视频监控、语音、办公数据的场景 |
| IPLC 国际专线 | 跨境点对点，带宽严格保证且独享，香港方向时延可低至 50ms 以内 | 跨国企业数据中心互联、跨境业务 |
| VPN 虚拟专线 | IPSec/SSL 加密隧道，年费比物理专线低 60%–80% | 分支机构远程接入、移动办公 |

各家运营商的叫法不完全一致，比如中国移动的互联网专线就分为 PON 接入和 PTN 接入两类。谈方案时先问清楚对应的是哪种传输方式，再对照上表判断适不适合自己。

## 专线为什么贵？报价单上要先看清两件事

专线贵，一部分贵在明面上的年费，一部分藏在报价细节里。

明面上的部分：同速率条件下，专线年费一般是共享带宽的 5–8 倍，带宽每升一档，费用跟着继续涨。换回来的是独享带宽、对称上下行、固定公网 IP 和 SLA 保障，钱花在哪是清楚的。

容易踩坑的是细节。**接入速率和带宽是两回事**：接入速率指接入线路能达到的最高限速，好比高速公路限速 120km/h；带宽是线路传送数据的能力，相当于路的宽度。一份只写“百兆接入”的报价单，既没说独享还是共享，也没说上行给多少——这三件事不确认，几个价格数字之间没有可比性。

> 拿到报价先问三个问题：这个带宽是独享还是共享？上行速率给多少？可用性和故障赔付写没写进 SLA？

## 这几种情况，先别急着上专线

50 人以下、业务以日常办公为主的小微团队，专线大概率是多余的。多线共享带宽做负载均衡，配上智能 QoS 策略把关键业务流量的优先级提上去，在控制成本的前提下就能拿到不错的网络体验，省下来的钱按专线 5–8 倍的年费差算，并不是小数目。

反过来，下面这几类场景别省这笔钱：

- 核心业务系统跑在公网上，中断的损失能直接算出来
- 实时交易平台，时延和抖动直接影响成交
- 要对接政务或监管平台，必须有固定公网 IP
- 跨境业务对时延敏感

这几类需求里，专线解决的已经不是“快一点”，而是“稳不稳、断不断”。

## 常见问题

### 专线和普通宽带的资费差多少？

同速率条件下，专线年费一般是共享带宽的 5–8 倍，带宽每升一档还会继续上涨。换来的是独享带宽、上下行对称、固定公网 IP 和 SLA 保障。

### 家庭宽带能不能凑合当专线用？

偶尔远程办公可以凑合，跑业务不建议。动态 IP 做不了对外服务和平台对接；上行通常只有 30M 以内，视频会议和文件回传会先卡在上行；共享池晚高峰波动，也没有 SLA 兜底。

### 100M 专线的上行也是 100M 吗？

是。专线上下行对称，100M 专线意味着双向都能稳定跑到 100Mbps，这也是它和家庭宽带最实际的差别之一。

### 跨境组网一定要用 IPLC 吗？

对时延和稳定性要求高的跨境业务，IPLC 是主流选择，香港方向时延可以做到 50ms 以内；如果只是分支机构的远程接入，VPN 虚拟专线便宜 60%–80%，一般够用。
